# Installing Subveris Tracker on Firefox

Subveris Tracker works on **Firefox 48+**. Installation is quick and straightforward!

## Requirements

- **Firefox 48 or later** (Released August 2016)
- **5 MB of free disk space**

## Installation: From Firefox Add-ons Store (Recommended)

The easiest way to install Subveris Tracker is from the official Firefox Add-ons store:

1. **Open Firefox**
2. **Go to:** [Subveris Tracker on Firefox Add-ons](https://addons.mozilla.org/firefox/addon/subveris-tracker/) 
   - Or search for "Subveris Tracker" in Firefox Add-ons
3. **Click "Add to Firefox"** button
4. **Review permissions** and click "Add"
5. **Done!** The extension appears in your toolbar

That's it! You'll receive automatic updates whenever new versions are released.

## First Time Setup

After installation:

1. **Open the Subveris app** in Firefox (go to subveris.app)
2. **Log in** with your account
3. **Go to Settings → Connected Services**
4. **Click "Connect Gmail Account"** (optional but recommended)
5. **Grant permissions** when Firefox asks

✅ Extension is now active and tracking!

## Verify It's Working

1. **Visit a subscription site** (Netflix, Spotify, etc.)
2. **Open the Subveris extension** (toolbar icon)
3. **Look for "Auto Discovery Methods"** section
4. Check your **Dashboard** for newly detected subscriptions

## If You Need to Reinstall

If you uninstalled and want to reinstall:

1. Go back to [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/subveris-tracker/)
2. Click "Add to Firefox" again
3. All your settings are preserved in your Subveris account
- ✅ Read Gmail (OAuth only)
- ✅ Detect downloads

Click **"Add"** to grant all permissions.

## Troubleshooting

### Extension not appearing in toolbar

**Problem**: Subveris icon doesn't show  
**Solution**:
1. Open Firefox Menu → Add-ons & Extensions
2. Search for "Subveris Tracker"
3. If found, ensure the toggle is enabled (blue)
4. Restart Firefox if needed

### Gmail connection fails

**Problem**: Can't authenticate with Gmail  
**Solution**:
- Make sure you're logged into Google in Firefox
- Check that Firefox allows pop-ups for subveris.app:
  1. Click the address bar icon (🔒)
  2. Go to Permissions
  3. Ensure pop-ups are allowed
- Try clearing Firefox cookies and trying again

### Website tracking not working

**Problem**: Visits to Netflix/Spotify aren't detected  
**Solution**:
1. Verify the extension is enabled (Firefox Menu → Add-ons → check toggle)
2. Visit the subscription site and let it fully load
3. Open the Subveris extension popup
4. Look for "Auto Discovery" status
